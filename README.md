# Rare Nail It · Web

Sitio estático de **Rare Nail It**, manicure y uñas a domicilio en Lima, Perú (soft gel, builder, poly gel, acrílico y nail art).

- Web: https://caro2870.github.io/rare-nail-it/
- Instagram: https://www.instagram.com/rare.nail.it/

## Editar datos
En `index.html`, al final, el bloque `CONFIG` tiene el número de WhatsApp y el enlace de reseñas de Google.
Precios, distritos y horario están en el HTML, en el JSON-LD del `<head>` y en `llms.txt` (deben coincidir).

Ver `GUIA-POSICIONAMIENTO.md` para SEO local y GEO (IA).
